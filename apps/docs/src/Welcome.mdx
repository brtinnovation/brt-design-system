# BRT Design System

Storybook รวมของทุก package — แต่ละกลุ่มใน sidebar คือ Storybook ของ package นั้น (render แยก iframe)

- **@brt-innovation/design — Tokens** — สีทุก palette, semantic color, typography, scale และวิธีใช้ CSS variable
- **@brt-innovation/antd** — component ของ Ant Design v6 ภายใต้ `BrtConfigProvider`

เลือก **brand** จาก toolbar ด้านบนของแต่ละกลุ่ม — `default` คือค่าจาก Figma, `example` คือ brand ตัวอย่างที่ประกาศด้วย `defineBrand()` แบบที่โปรเจกต์ทำ

รันทั้งหมดด้วย `pnpm storybook` ที่ root แล้วเปิด http://localhost:6006
